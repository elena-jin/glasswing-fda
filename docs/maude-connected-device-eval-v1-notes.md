# Connected-device MAUDE evaluation set - September 26, 2026

214 **real public MAUDE narratives** in a separate **held-out eval-only** JSON file: 65 continuous glucose monitors, 70 insulin pumps, 75 cardiac telemetry monitors and 4 CPAP devices. Each contains the FDA report key, report number, received date, product code, query URL, device family, narrative text, redaction metadata and a **provisional complaint / human Quality-review candidate** label. No source case was added to train. No safe product-feedback negatives are in this set. Do not train, tune prompts, select thresholds or claim generalization on it. Human Quality reviewers should adjudicate the labels and any possible MDR flag before production use.

Source: [openFDA device adverse-event API](https://open.fda.gov/apis/device/event/) and underlying [MAUDE dataset](https://open.fda.gov/data/maude/). Queries used `device.device_report_product_code` QBJ (CGM), QFG (alternate-controller insulin pump), BZD (non-continuous ventilator/CPAP) and DRT (cardiac monitor); received dates 2024-01-01 to 2026-09-26. Raw fetch returned the first 300 results for each code, plus first 300 for `mdr_text.text:app` per code (BZD had only 11 app matches and DRT none). Local selection required a connected-app/control/telemetry cue and a possible deficiency; one "Description of Event or Problem" per report was kept. The file was capped by family, seeded sampled, and deduplicated by exact normalized narrative and first 150 chars to reduce repeated manufacturer boilerplate. Thus **not a random or representative sample**, not all records explicitly about mobile apps (cardiac telemetry includes central nurse stations and transmitters). Especially CGM reports can repeat near-identical wording beyond the 150-character check. These are FDA received reports, not independent proof of device malfunction, causation or clinical harm.

Narrative text is unchanged except for 3 cases in which exact dates were masked as `[DATE REDACTED]`; existing FDA `(B)(6)` marks are retained. Headers with complainant name, address, age, lot, UDI and contact information are excluded. Automated de-identification is not a guarantee: get privacy review before wider redistribution. The text may include staff paraphrases or first-person reporter statements; do not infer direct customer quotation from the record type.

[openFDA license](https://open.fda.gov/license): generally public domain/CC0, subject to third-party rights, privacy/publicity and GMDN exceptions. [Service terms](https://open.fda.gov/terms) apply. FDA warns data are unvalidated, may be incomplete/biased, and cannot determine event incidence; [endpoint explanation](https://open.fda.gov/apis/device/event/) confirms those limitations. Use per-report keys and source query URLs to retrieve and inspect originals when a label is disputed.

For measurement, score this as **complaint-only sensitivity stress testing** and report it separately from the mixed six-case real seed and v1.1 synthetic held-out eval. Its false-positive rate is undefined without de-identified, permissioned real safe feedback. Score by family and error mode; do not aggregate into one misleading accuracy statistic. Potential MDR fields are `null` intentionally because no reportability decision was made.
